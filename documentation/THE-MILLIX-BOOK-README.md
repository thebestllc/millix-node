## 📊 What is Millix?

**Millix** is a cryptocurrency built on a modified DAG (Directed Acyclic Graph) structure, optimized for peer-to-peer digital cash.

### Key Features

🚀 **Fast**: Transactions confirm in ~10 seconds  
💰 **Predictable**: Every transaction costs exactly 1,000 millix  
🌐 **Decentralized**: 14,000+ equal nodes, no special privileges  
💾 **Lightweight**: Runs on a Raspberry Pi  
🎨 **NFT-Native**: Protocol-level NFT support  
📦 **Data Storage**: Encrypted data on the DAG  

### Proven Track Record

✅ 5+ years operational (since January 2020)  
✅ 1,000,000+ transactions processed  
✅ 100,000+ tx/day capacity proven  
✅ Zero downtime since genesis  
✅ 9 quadrillion fixed supply (no inflation)  

### Learn More

- **Website**: https://millix.org
- **GitHub**: https://github.com/millix
- **Ecosystem**: https://tangled.com
